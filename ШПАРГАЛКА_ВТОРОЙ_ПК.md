# ⚡ Шпаргалка для второго ПК

## 🚀 Быстрая настройка (делать один раз)

### 1. Установить программы:
- **Git:** https://git-scm.com/download/win
- **Python:** https://python.org/downloads
- **Cursor:** https://cursor.sh (опционально)

### 2. Настроить Git:
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

### 3. Клонировать проект:
```bash
cd Documents
git clone https://github.com/EmilioSedici16/TST_git_repository.git
cd TST_git_repository
# Переименовать в TST_Project (опционально)
cd .. && ren TST_git_repository TST_Project && cd TST_Project
pip install -r requirements.txt
```

## 📅 Ежедневная работа

### ▶️ ПЕРЕД работой:
```bash
cd TST_Project
git pull origin main
```

### ◀️ ПОСЛЕ работы:
```bash
git add .
git commit -m "Что изменили"
git push origin main
```

## 🔧 Полезные команды

```bash
git status          # Что изменилось
git log --oneline   # История изменений
dir                 # Содержимое папки (Windows)
python extract_frames.py  # Запуск основного скрипта
```
