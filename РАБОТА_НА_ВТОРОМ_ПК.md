# 💻 Работа на втором компьютере - Пошаговая инструкция

## 🎯 Цель
Настроить синхронизацию проекта TST_Project между двумя компьютерами через Git/GitHub.

## 📋 Что нужно сделать

### 1️⃣ НА ПЕРВОМ ПК (текущем):

#### А) Завершить настройку Git:
1. **Запустить автоматическую настройку:**
   - Дважды кликните `setup_git.bat`
   - ИЛИ в PowerShell: `.\setup_git.ps1`

2. **Создать репозиторий на GitHub:**
   - Перейти на https://github.com
   - Нажать "New repository"
   - Название: `TST_Project`
   - **ВАЖНО:** НЕ добавлять README, .gitignore, license
   - Нажать "Create repository"

3. **Ввести GitHub username** когда скрипт попросит

#### Б) Проверить, что всё загружено:
```bash
git status
git log --oneline
```

### 2️⃣ НА ВТОРОМ ПК:

#### А) Установить необходимое ПО:
1. **Git:**
   - Скачать: https://git-scm.com/download/win
   - Установить с настройками по умолчанию

2. **Python:**
   - Скачать: https://python.org/downloads
   - При установке отметить "Add to PATH"

3. **Cursor (опционально):**
   - Скачать: https://cursor.sh

#### Б) Настроить Git (один раз):
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

#### В) Клонировать проект:
```bash
# Перейти в нужную папку (например, Documents)
cd Documents

# Клонировать ваш существующий репозиторий
git clone https://github.com/EmilioSedici16/TST_git_repository.git

# Перейти в папку проекта
cd TST_git_repository

# Переименовать папку в TST_Project (опционально)
cd ..
ren TST_git_repository TST_Project
cd TST_Project

# Установить зависимости Python
pip install -r requirements.txt
```

#### Г) Проверить работу:
```bash
# Проверить структуру проекта
dir

# Проверить Git статус
git status

# Протестировать скрипт
python extract_frames.py
```

## 🔄 Ежедневная синхронизация

## ⚠️ Важные правила

### ✅ ОБЯЗАТЕЛЬНО:
- **ВСЕГДА** делать `git pull` перед работой
- **ВСЕГДА** делать `git push` после работы
- Использовать понятные сообщения в коммитах
- Не работать одновременно на двух ПК

### ❌ ИЗБЕГАТЬ:
- Работы без git pull/push
- Одновременной работы на двух ПК
- Изменения файлов в .git папке
- Удаления .gitignore или .gitkeep файлов

## 🔧 Решение проблем

### Проблема: "fatal: not a git repository"
```bash
# Убедитесь, что находитесь в папке проекта
cd TST_Project
pwd  # (Linux/Mac) или cd (Windows) - показать текущую папку
```

### Проблема: Конфликты при git pull
```bash
git stash              # Сохранить локальные изменения
git pull origin main   # Получить изменения с GitHub
git stash pop          # Восстановить локальные изменения
# Разрешить конфликты в файлах если есть
git add .
git commit -m "Исправлены конфликты"
git push origin main
```

### Проблема: "Permission denied" при git push
```bash
# Настроить аутентификацию через Personal Access Token
# Инструкция: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/creating-a-personal-access-token
```

### Проблема: Python модули не найдены
```bash
# Убедиться, что находитесь в папке проекта
cd TST_Project

# Переустановить зависимости
pip install -r requirements.txt

# Проверить версию Python
python --version
```

## 🎉 Проверка успешной настройки

После настройки второго ПК:

1. **Создать тестовый файл на втором ПК:**
   ```bash
   echo "Тест со второго ПК" > test_second_pc.txt
   git add test_second_pc.txt
   git commit -m "Тест со второго ПК"
   git push origin main
   ```

2. **Проверить на первом ПК:**
   ```bash
   git pull origin main
   # Должен появиться файл test_second_pc.txt
   ```

3. **Удалить тестовый файл:**
   ```bash
   git rm test_second_pc.txt
   git commit -m "Удален тестовый файл"
   git push origin main
   ```

✅ **Если всё работает - синхронизация настроена правильно!**
