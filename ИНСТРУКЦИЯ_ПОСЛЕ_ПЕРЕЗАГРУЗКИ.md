### 4. **Настроить доступ к UTair Cloud:**

#### Вариант A - WebDAV (рекомендуемый):
1. Windows Explorer → Этот компьютер → Подключить сетевой диск
2. Адрес: `https://cloud.utair.ru/remote.php/dav/files/ВАШ_ЛОГИН/TST_project/Videos`
3. Выбрать букву диска (например, Z:)
4. Ввести логин/пароль UTair
5. Создать ссылку: `mklink /D Videos "Z:\TST_project\Videos"`

#### Вариант B - Ручная загрузка:
- Скачивать видео через https://cloud.utair.ru/apps/files/?dir=/TST_project/Videos

### 5. **Установить зависимости:**
```bash
pip install -r requirements.txt
```

### 6. **Протестировать проект:**
```bash

python test_basic.py

# Извлечение кадров:
```
