## 🎯 Описание
Полный pipeline для компьютерного зрения: от извлечения кадров из видео до детекции объектов с помощью Roboflow и YOLO. Проект включает синхронизацию с UTair Cloud и автоматизированную работу на двух компьютерах.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### 🎬 Извлечение кадров (30 кадров с равномерным распределением)
```bash
# Способ 1: Интерактивный батник (рекомендуется)
ИЗВЛЕЧЬ_30_КАДРОВ.bat

# Способ 2: Python скрипт
python extract_frames.py

# Способ 3: Продвинутое извлечение
python extract_30_frames.py
```

## 🔧 Файлы проекта

### 🎬 Извлечение кадров
- **`extract_frames.py`** - основной скрипт (30 кадров, равномерное распределение)
- **`extract_30_frames.py`** - продвинутая версия с облачным сохранением
- **`ИЗВЛЕЧЬ_30_КАДРОВ.bat`** - интерактивное извлечение кадров
- **`ПОЛНЫЙ_PIPELINE.py`** - автоматический pipeline извлечение → Roboflow → детекция

### ⚙️ Настройка системы
- **`ДОБАВИТЬ_PYTHON_В_PATH.bat`** - автоматическая настройка Python PATH
- **`УСТАНОВИТЬ_БИБЛИОТЕКИ.bat`** - установка всех необходимых библиотек
- **`test_python.py`** - диагностика системы и проверка готовности
- **`install_libraries.py`** - Python скрипт установки библиотек

### 🌐 Работа с UTair Cloud
- **`НАСТРОИТЬ_ОБЛАКО.bat`** - настройка синхронизации с UTair Cloud
- **`check_cloud_sync.py`** - мониторинг синхронизации и интерактивные действия
- **`Add-Python-To-PATH.ps1`** - PowerShell версия настройки PATH

### 📚 Документация и инструкции
- **`НАЧАТЬ_РАБОТУ_ROBOFLOW.md`** - быстрый старт для полного pipeline
- **`ИНСТРУКЦИЯ_30_КАДРОВ.md`** - детальное описание извлечения кадров
- **`СИНХРОНИЗАЦИЯ_UTAIR_CLOUD.md`** - работа с облачным хранилищем
- **`УСТАНОВКА_БИБЛИОТЕК.md`** - установка Python библиотек

## 🌐 Работа с Git

### 🆕 Первая настройка
Запустите один из файлов:
- **`setup_git.bat`** - автоматическая настройка для Windows
- **`setup_git.ps1`** - PowerShell версия настройки

Или следуйте инструкциям:
- **`QUICK_GIT_SETUP.md`** - быстрая настройка
- **`GIT_SETUP_INSTRUCTIONS.md`** - подробная инструкция

### 💻 Работа на разных компьютерах

#### Перед началом работы:
```bash
git pull origin main
```

#### После завершения работы:
```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

#### Клонирование на новом компьютере:
```bash
git clone https://github.com/ВАШ_USERNAME/TST_Project.git
cd TST_Project
pip install -r requirements.txt
```
