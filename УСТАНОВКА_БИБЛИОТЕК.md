## 🚨 Решение проблем

### ❌ "Python не найден"
1. Установите Python: https://python.org/downloads
2. При установке отметьте "Add to PATH"
3. Перезагрузите компьютер

### ❌ "pip не найден"
```cmd
python -m ensurepip --upgrade
```

### ❌ Ошибки установки
1. Запустите терминал от имени администратора
2. Обновите pip:
   ```cmd
   python -m pip install --upgrade pip
   ```
3. Попробуйте установить по одной библиотеке:
   ```cmd
   python -m pip install opencv-python
   python -m pip install numpy
   ```

### ❌ Проблемы с opencv-python
Попробуйте альтернативную версию:
```cmd
python -m pip install opencv-python-headless
```

### ❌ Медленная установка
Используйте зеркало:
```cmd
python -m pip install -i https://pypi.douban.com/simple/ opencv-python numpy
```

## 💡 Полезная информация

### 📊 Размеры библиотек:
- opencv-python: ~35 MB
- numpy: ~15 MB

- Общий размер: ~50-100 MB

### ⏱️ Время установки:
