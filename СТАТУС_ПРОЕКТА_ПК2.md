## 🛠️ **Настройка на ПК№2:**
```bash
# 1. Подключить UTair Cloud:
# В Windows Explorer → Подключить сетевой диск
# Адрес: https://cloud.utair.ru/remote.php/dav/files/ВАШ_ЛОГИН/TST_project/Videos

# 2. Создать символическую ссылку:
mklink /D Videos "Z:\TST_project\Videos"

# 3. Установить зависимости:
pip install -r requirements.txt

# 4. Тестирование:
python diagnostic_script.py
python video_to_images.py --help
```
