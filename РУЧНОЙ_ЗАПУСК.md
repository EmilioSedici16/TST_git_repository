# 🔧 Ручной запуск извлечения кадров

## ⚠️ Проблема
Терминал в Cursor имеет проблемы с кодировкой, поэтому команды не выполняются корректно.

## ✅ Решение: Ручной запуск

### 🐍 1. Проверка Python

#### Способ А: Через проводник Windows
1. Откройте папку проекта в Проводнике Windows
2. Дважды кликните на файл `test_python.py`
3. Если откроется черное окно с информацией - Python работает!

#### Способ Б: Через внешний терминал
1. Нажмите `Win + R`
2. Введите `cmd` и нажмите Enter
3. Выполните команды:
   ```cmd
   cd "C:\Users\Sitdikov_ER\Documents\TST_Project"
   python test_python.py
   ```

### 🎬 2. Извлечение кадров

#### Способ А: Через батник (рекомендуемый)
1. В Проводнике Windows дважды кликните: `ИЗВЛЕЧЬ_30_КАДРОВ.bat`
2. Следуйте инструкциям в открывшемся окне

#### Способ Б: Через внешний терминал
```cmd
cd "C:\Users\Sitdikov_ER\Documents\TST_Project"
python extract_frames.py
```

#### Способ В: Продвинутое извлечение
```cmd
cd "C:\Users\Sitdikov_ER\Documents\TST_Project"
python extract_30_frames.py
```

### 🔍 3. Проверка результатов

#### Способ А: Через батник
```cmd
python check_cloud_sync.py
```

#### Способ Б: Ручная проверка
1. Откройте папку `Images` в проводнике
2. Проверьте наличие подпапок с именами видео
3. В каждой подпапке должно быть 30 кадров

### 🌐 4. Проверка облака
Откройте в браузере: https://cloud.utair.ru/apps/files/?dir=/TST_project

## 📋 Пошаговый план

## 🚨 Если что-то не работает

### Python не найден:
1. Проверьте установку Python
2. Добавьте Python в PATH
3. Перезапустите компьютер

### OpenCV не установлен:
```cmd
pip install opencv-python
```

### Видео не найдены:
1. Запустите `НАСТРОИТЬ_ОБЛАКО.bat`
2. Настройте подключение к UTair Cloud
3. Проверьте https://cloud.utair.ru/apps/files/?dir=/TST_project/Videos

### Кадры не извлекаются:
1. Проверьте права доступа к папкам
2. Убедитесь что видеофайлы не повреждены
3. Попробуйте другой режим извлечения
